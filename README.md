# AI-Minds-and-Robotic-Bodies-Intuitive-Mind-Body-Dualism-Shapes-Prosociality-Towards-Machines
Repository for the survey materials, R analysis code, Experiment 2 data, and supplementary materials for two studies on the interplay of mind and body on social and moral attitudes towards AIs.

The Experiment 1 data is published on Mendeley Data (https://data.mendeley.com/datasets/x5689yhv2n/4). Additional supporting R code for Experiment 1 is available on the OSF (https://osf.io/mn546).

Both experiments were preregistered on the OSF (Experiment 1: https://osf.io/hz3me, Experiment 2: https://osf.io/qm9vw).
